How it works & coverage

Arkansas first. All 50 states on the roadmap.

We start deep in one state so the data is right, then expand. Here's how collection works and where coverage is headed.

How it works

  1. CollectScheduled collection from public state sources: procurement portals, award notices, legislative sites, Medicaid and procedure manuals, rule registers, and news.
  2. Record provenanceEach item keeps its source link and collection date.
  3. OrganizeItems are classified by state, agency, program area, and type, then de-duplicated.
  4. AnalyzeAI search, dashboards, league tables, and insights are built on top of the organized records.
