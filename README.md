## Stripe checkout

Live Payment Links are in `src/checkout-config.js` (copied to `assets/js/checkout-config.js` on build). Only `buy.stripe.com` / `checkout.stripe.com` URLs are accepted; anything else is ignored. Buttons with a filled slot go to Stripe; an empty slot keeps the mailto fallback.

| Key | Price | Payment Link |
| --- | --- | --- |
| `trial` | Limited-time $64 (regularly $129), one-week (7-day) trial, 1 user | https://buy.stripe.com/4gMaEXa1bcqQcx1ay8f3a0Y |
| `per-user-monthly` | Limited-time $99/month per user (regularly $199/month) | https://buy.stripe.com/00w5kD6OZgH68gL21Cf3a10 |
| `per-user` | Limited-time $999/year per user (regularly $1,999/year) | https://buy.stripe.com/28E4gzehrfD20Oj9u4f3a11 |
| `foia` | $199 per FOIA request (no sale) | https://buy.stripe.com/5kQ28r0qBeyYaoT0Xyf3a0Z |
| `foia-5pack` | $899 for 5 FOIA requests (no sale) | https://buy.stripe.com/00wdR9gpzbmMeF95dOf3a12 |
| `enterprise` | Custom, 10+ seats | Empty on purpose. Contact sales stays a mailto link. |

Each filled Payment Link should redirect after payment to `https://statewatchpro.com/thank-you.html`. Stripe Payment Links have no cancel URL; `checkout-canceled.html` is available if you later use Checkout Sessions or link to it yourself.

The free FOIA request, the quarterly report, and the quarterly webinar are for annual members only. They are not included with Professional monthly or the one-week trial.

Rebuild, run `python3 test_site.py <url>`, and deploy. Never put Stripe secret or publishable keys in the checkout config or anywhere in the site.

The FOIA intake form always emails the request details. The `foia` slot is the $199 payment button. Annual members request their 1 free FOIA filing per year on the intake form (annual plans only, not monthly) and do not use the payment link for that included request.
