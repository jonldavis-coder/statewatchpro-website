# StateWatchPro marketing site (preview)

Generated by `src/build.py`. Do not hand-edit HTML; edit the generator and rebuild.

## Turning on Stripe checkout (after the custom domain is live)

1. In Stripe, create a Payment Link for each plan you want to sell online: trial ($129 one-week), Professional per-user ($1,999/yr), optionally Enterprise (custom), and FOIA filing ($199 per request).
2. In each Payment Link's **After payment** settings, choose "Redirect customers to your website" and enter `https://<your-domain>/thank-you.html`. (Stripe Payment Links have no cancel URL; `checkout-canceled.html` is available if you later use Checkout Sessions or link to it yourself.)
3. Open `assets/js/checkout-config.js` (source: `src/checkout-config.js`) and paste each `https://buy.stripe.com/...` URL between the quotes for its plan. Only `buy.stripe.com` / `checkout.stripe.com` URLs are accepted; anything else is ignored.
4. Rebuild, run `python3 test_site.py <url>`, and deploy. Buttons with a filled slot go to Stripe; empty slots keep the mailto fallback.
5. Never put Stripe secret or publishable keys in this file or anywhere in the site.

Enterprise is set up as "Contact sales" (mailto) by default; fill its slot only if you want self-serve Enterprise checkout.

The FOIA intake form always emails the request details. The `foia` slot is the $199 payment button: a filled `buy.stripe.com` or `checkout.stripe.com` link sends that button to Stripe, and an empty slot keeps it as email. Annual members request their 1 free FOIA filing per year on the intake form (annual plans only, not monthly) and do not use the payment link for that included request.
